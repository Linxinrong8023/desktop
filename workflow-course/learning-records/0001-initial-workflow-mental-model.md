# Initial workflow mental-model baseline

Before taking the first lesson, the learner correctly identified Draft as editable and a published Snapshot as version-like frozen data. The learner currently treats Run and NodeRun as statuses rather than execution records, and treats every node as equivalent to a Session; future lessons should reinforce entity-versus-status and NodeRun-versus-Session boundaries with concrete persisted rows.

## Evidence

The learner explained all five terms from prior intuition and explicitly stated that the lesson had not yet been read.

## Implications

Begin with one concrete run instance and repeatedly ask “is this a record, or a field on that record?” before introducing deeper state-machine details.
