节点能力速查

先看生产闭环，再看解析兼容，最后看 mock 元数据。不要反过来推断功能已经存在。

节点 所在层 Run 行为 Session
Start 生产可执行 同步完成，输出 Run input 无
Agent 生产可执行 异步 Session；支持 HITL 有
Output 生产可执行 同步拼接直接前驱 outputs 无
Prompt 已知但不支持 启动 Run 时拒绝；前端可升级为 Agent 无执行
Condition 已知但不支持 启动 Run 时拒绝 无执行
Tool 已知但不支持 启动 Run 时拒绝 无执行
Junction mock/prototype 创建 Run 解析图时未知 无执行
Human mock/prototype 创建 Run 解析图时未知 无执行
Loop mock/prototype 创建 Run 解析图时未知 无执行
Subflow mock/prototype 创建 Run 解析图时未知 无执行

快速判断顺序

UI 有名称 / 表单
↓ 只能证明展示或原型存在

Rust NodeType 能解析
↓ 只能证明后端认识字符串

supported() 接受
↓ 证明可以进入 v1 调度

有同步完成者或 NodeExecutor
↓ 才形成生产执行闭环
