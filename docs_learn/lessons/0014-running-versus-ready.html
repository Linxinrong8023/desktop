Lesson 0014 · 区分两层状态

插件 Running，为什么 Agent 仍可能不可用？

Running 只证明插件的 Deno 进程活着；Ready 还要求它成功拉起 Agent CLI，并完成 ACP 握手。

一层一层看

main.js Deno 进程启动并完成插件注册
  ↓
Plugin Lifecycle：Running
  ↓
main.js 尝试拉起 Agent CLI
  ↓
Ora 与 Agent CLI 完成 ACP initialize
  ↓
Connection Supervisor：Ready

在连接建立过程中，插件进程可以已经是 Running，但 Agent 连接还不能成为 Ready。如果后续启动或握手失败，Supervisor 会请求 Lifecycle 停止这一代插件进程，再按策略重试，所以这些状态会继续变化。

常见例子

CLI 没安装：main.js 还活着，但找不到真正的 Agent 程序。

配置或环境错误：CLI 启动失败，插件外壳本身没有退出。

ACP 握手失败：CLI 已启动，但 initialize 超时或返回错误。

Agent 合同不完整：插件已注册为运行中，但缺少 Agent 必需的 method 或 agent/acp emit，Supervisor 会把它判为不可服务。

这一课唯一要记住的句子：插件进程存活是 Agent 可用的必要条件，但不是充分条件。
