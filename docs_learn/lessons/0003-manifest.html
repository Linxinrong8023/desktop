Lesson 0003 · Manifest

Ora 怎样认出一个插件？

一个目录里可能有 JavaScript、图片和说明文件。Ora 不能靠猜，需要一张格式固定的“插件身份证”：orax.toml。

Manifest 是什么

Manifest 中文通常叫“清单”。它是插件包根目录中的一个文本文件，告诉 Ora：我是谁、属于谁、是哪种插件、版本是多少。

它类似快递箱外面的面单。面单描述箱子，而不是箱子里的机器本身；同样，Manifest 描述插件，但不会替代插件代码运行。

identifier = "my-agent"
namespace = "official"
kind = "agent"
version = "1.2.0"
description = "An Agent plugin"

这五项先这样理解

namespace + identifier共同组成插件的唯一身份，例如 official/my-agent。
kind说明它贡献什么能力，例如 Agent、Skill 或 MCP。
version说明当前包是哪一个版本，并且必须与版本目录一致。
description是给人看的简介，不决定插件怎样运行。

为什么不能只看有没有 main.js

因为文件名只能说明“这里可能有一段代码”，却不能可靠说明插件身份、类型和版本。Ora 先严格解析并验证 Manifest，再根据 kind 检查这个插件包还必须有什么、禁止有什么。

自我声明不等于自动可信：插件自己写 kind = "agent" 只是声明。Ora 仍要检查字段是否合法、目录版本是否一致，以及 Agent 插件需要的文件是否真的存在。验证失败的包不能被当作正常插件运行。

初级面试表达：每个插件包用根目录下的 orax.toml 声明身份、类型和版本。Manifest 层只负责把文本解析成经过验证的结构；磁盘文件是否满足该类型的要求，则由 Plugin Manager 继续检查。
