# 工具服务接入

> 核对日期：2026-09-10；依据本地 `project_learn` 分支源码。本文是当前实现学习说明。

[返回学习导航](../README.md)

## 模块职责

学习 MCP 插件如何变成 Session 的工具服务快照，以及配置变化如何安全送到已运行的 Agent。

## 设计逻辑与执行流程

Session setup 收集有效且配置完整的 MCP 插件，按 canonical PluginId 排序生成一个 Snapshot。配置不完整的插件被排除；已构造集合的发送是整体成功或失败，不能偷偷发送一部分。

Stdio 解析为 ACP `McpServer::Stdio`，可执行文件重新检查为包内普通文件；HTTP 解析为 `McpServer::Http`，需要 Agent 声明 HTTP MCP 能力。workspace context 被解析成会话绝对 cwd，字面量 `.` 保持字面量语义。

快照通过 `session/new`／`session/load` 的 `mcpServers` 传递。非空集合要求 Agent 支持 session/load，保证后续配置更新可交付。

安装／卸载／设置变化只发送不含秘密值的唤醒。空闲 Session 立即刷新，忙会话等当前 prompt 完成，刷新期间阻止新 prompt。Desired 和 Active revision 在内存比较；刷新失败只阻塞对应 Session，下一轮重试。MCP 刷新与 Skill 变更／Agent 替换共享 Session Barrier 以避开执行中的危险时点。

## 数据库表与持久化

| 数据 | 存储 | 规则 |
| --- | --- | --- |
| 不可变服务定义 | 插件 `assets/config.json` | 描述 transport 和 Setting 引用 |
| 显式配置值 | 插件 `store.json` | 由配置服务保存 |
| 解析后的命令、env、header、Desired／Active revision | 短期内存 Snapshot／ACP 帧 | 按 Session setup／live refresh 生成 |
| Session 身份 | `sessions` | 只是关联执行会话，不存服务凭据 |

**没有 MCP 专用表，也不写 `effect_*`。** 不创建 `.mcp.json`、OpenCode 配置或工作区 ownership 文件。配置值不能进入 SQLite、Effect、日志、UI DTO、revision digest 或 Agent 环境变量；ACP 帧中的服务 env 与宿主进程环境注入是两回事。

## 目前存在的缺陷与限制

- **已确认的兼容限制**：不支持 session/load 的 Agent 遇到非空 MCP 集合会在 setup 前失败，即使它能创建普通对话。
- **已确认的限制**：不完整插件被排除，不能从“Agent 能对话”推断所有工具服务已接入。
- **已确认的可用性取舍**：刷新失败阻止后续 prompt，宁可会话暂时不可用也不悄悄使用旧配置。
- **信任边界**：实际值会交给受信任 Agent；这条路径不是对 Agent 隐藏凭据的代理保险库。
