# 从零基础重新开始插件系统课程

## Learner evidence

用户明确反馈：“说实话，我连概念都不懂，我没有基础啊。”

## Interpretation

- 之前的课程记录代表接触和讲解历史，不代表当前掌握程度。
- 第一版插件专题从 Package / Contribution / Runtime 开始，起点过高。
- 当前不能假设用户理解插件、程序、进程、协议、运行时或 Manifest。

## Teaching implications

- 第一课只建立“插件是什么”以及“内置与插件化的区别”。
- 每次只引入一个概念，先用生活类比，再给一句工程定义。
- 每课只要求一个核心复述问题；用户能够用自己的话解释后才进入下一课。
- 面试仍是第一目标，但先形成真实直觉，再逐渐压缩成面试表达。

## Mastery status

尚未验证任何插件系统核心概念。下一检查点：用户能否解释“为什么新增能力时，安装插件通常比修改并重新发布主程序更容易扩展”。
