Workflow 启动调用链

从 UI 命令到 Agent 后台任务，每层只承担自己的职责。

WorkflowRunWorkspace.handleStart
  → useStartWorkflowRun
  → client.workflowRun.start
  → executeOperation("startWorkflowRun")
  → Tauri start_workflow_run
  → Backend::start_workflow_run
       → acquire_exclusive(run_id)
  → WorkflowRunControlHandler::start
  → WorkflowRunEngine::start
       → parse graph / validate
       → repository.start_run
       → run_schedule
  → repository.start_ready_nodes
  → WorkflowRunNodeExecutor::dispatch
       → tokio::spawn(drive_agent_node)
  → 返回 Run = Running

两类失败

现象 含义 优先层
立即 Toast，Run 未启动 同步启动命令失败 Transport / Backend / Engine / DB
先 Running，随后 Failed 异步节点执行失败 Agent Executor / Session / ACP

一句话职责

UI：表达意图
Contract：传输命令
Backend：组合并串行化
Engine：决定状态机
DB Adapter：原子落库
Agent Executor：驱动 Session
