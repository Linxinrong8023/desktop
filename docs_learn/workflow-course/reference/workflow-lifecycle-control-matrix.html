Cancel / Restart / Recovery

用“目的、数据库动作、是否重新调度”区分三者。

操作 Run NodeRuns 后续
Cancel Running → Cancelled 非终态 → Cancelled 清空 current_nodes，best-effort 停 Session
Restart 非 Running → Pending → Running 旧记录软删除，新建一轮记录 同 run_id 从 Start 执行
Recovery: Running NodeRun → Failed 非终态 → Failed 不重放未知外部执行
Recovery: 合法 HITL 保持 Running Pending 保留 继续等用户
Recovery: 调度断档 保持 Running 保留已成功记录 重算 Ready，补调度后继

一句话记忆

Cancel  = 把正在发生的事情收口
Restart = 清空本轮可见执行，从头重跑
Recovery = 相信已提交事实，不猜外部执行结果
