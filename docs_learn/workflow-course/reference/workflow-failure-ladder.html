Agent 故障证据阶梯

先找最后一个持久化检查点，再检查它与下一个检查点之间的链路。

数据库现象 已经证明 下一步
无 NodeRun 没有成功进入持久化 ready wave 查前驱、DAG、启动门禁、调度事务
Running / session_id NULL 已调度，尚未成功绑定 Session 查配置、warm/attach、模型、Prompt admission、失败回调
Running / session_id 有值 owning prompt 已接受并完成绑定 查 ACP 流、Agent CLI、stop reason、完成回调
Pending / session_id 有值 可能是合法 interactive HITL 用冻结图确认 interactive，再查人工续聊或完成动作
Failed / error 有值 失败已经落库，Run 终止 先读 error，再用 session_id 区分绑定前后
Succeeded / 后继无 NodeRun 当前节点已完成，续调度尚未留下事实 查 run_schedule 与启动 reconcile

Agent 节点检查点

Ready（内存）
  → NodeRun Running（持久化）
  → dispatch
  → warm / attach
  → prompt admitted
  → session_id bound（持久化）
  → ACP events
  → Succeeded / Failed / Pending（持久化）
  → run_schedule

WorkflowRun.status
WorkflowRun.state.current_nodes
WorkflowNodeRun.status
WorkflowNodeRun.session_id
WorkflowNodeRun.error
