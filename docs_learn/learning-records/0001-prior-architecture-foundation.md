# 历史课程接触记录（已被 LR-0002 校正）

本记录曾根据已有课程文档，推断用户已经掌握 ACP、进程监督、generation、Session actor、Warm Session、Agent 换绑、Skill 与 Workflow 等概念。

该推断不成立。历史文档只能证明这些内容曾被讲解，不能证明用户已经形成理解或能够独立复述。以用户在 LR-0002 中的明确反馈为准。

## Evidence

`lesson-07.md`、`lesson-11.md`、`lesson-12.md` 和 `lesson-17.md` 记录过对应内容，但尚未在当前课程中重新验证。

## Implications

不得把“曾经看过”当成“已经掌握”。插件专题必须从零基础重新建立概念，并通过用户自己的复述逐步验证。
