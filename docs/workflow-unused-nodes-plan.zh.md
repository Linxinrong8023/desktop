# 工作流未使用节点实现方案

[English](workflow-unused-nodes-plan.md) | 中文

状态：已实现。本文保留设计与验收范围；实际行为见 [工作流文档](workflow.zh.md)。

## 目标与范围

工作流编辑过程中，允许用户为调试保留未接入执行路径的单个节点或整组备用节点。
完整画布保留在草稿和发布快照中，运行时只执行从入口可达的子图。
本方案不引入手动禁用开关或独立节点试运行功能。

## 变更前机制与限制

- `crates/application/src/workflow/handlers.rs` 的草稿保存和发布 handler 保存图或创建快照，未在该处执行可达性校验。
- `crates/application/src/workflow_run/engine/engine.rs` 的启动逻辑通过 `UnreachableNodes` 拒绝从 Start 不可达的节点。
- `crates/application/src/workflow_run/engine/loop_graph.rs` 要求各作用域的节点从该作用域的 Start 可达。
- `crates/application/src/workflow_run/engine/iteration.rs` 要求所有 Iteration 成员从容器入口边可达。
- `crates/application/src/workflow_run/engine/branch_projection.rs` 将没有入边的节点判定为 `Ready`。只删除可达性检查可能导致孤立节点被执行。
- `crates/backend/src/workflow/run/prerequisites.rs` 遍历各作用域全部 Agent 解析角色和 Skill。仅修改调度仍会让备用节点的依赖问题阻塞运行。

## 行为定义

“未使用节点”指从所属作用域的有效入口沿有向边不可达的节点，不仅限于完全没有连线的节点。

```text
Start → A → Output       正常执行
B → C                    保留，不执行
D                        保留，不执行
```

1. 根作用域从 Start 计算可达性。
2. Loop 只有在外层可达时才参与执行；其内部从自己的 Start 计算可达性。
3. Iteration 只有在外层可达时才参与执行；其内部从容器入口边计算可达性。容器有效性仍需满足现有执行约束，例如活动 Iteration 需要有效入口成员。
4. 未使用容器的全部成员均不参与执行，内部局部连通不改变这一结论。
5. Condition 的全部出口参与静态可达性分析。运行时未命中的分支继续使用现有分支机制，与未使用节点区分。
6. 未使用节点不创建 NodeRun 或 Session，不解析运行依赖，不等待交互输入，不影响完成判定。
7. 节点连接回执行路径后，自动恢复正常执行校验。
8. 不持久化 `enabled` 或 `unused` 字段，参与范围由图结构推导。

以下情况也必须正确处理：

```text
Start → A → Output
B ─────→ A
```

B 从 Start 不可达，因此执行子图排除 B 及其指向 A 的边，A 不等待 B。
若 A 的配置引用 B 的输出，则在执行校验中返回明确错误，不将缺失值静默转换为空值。
变量引用不会隐式激活未使用节点。

## 后端设计

在 `workflow_run` 领域中新增独立模块，统一从完整文档推导执行图，避免继续扩充较大的 `graph.rs`。
模块名称与具体类型在实现时确定，但其职责和处理顺序如下：

```text
完整工作流文档
    ↓
文档结构检查与作用域划分
    ↓
计算参与执行的节点和边
    ↓
解析执行节点配置并校验执行子图
    ↓
运行前准备、调度与恢复
```

必须先确定执行范围，再解析参与执行节点的完整配置。
当前完整解析已检查配置和容器成员，先解析后过滤仍会让备用节点未完成的配置阻塞运行。
前置文档解析只读取推导拓扑及作用域所需的字段，保留原始配置供后续处理。

### 校验边界

| 范围     | 规则                                                                                                         |
| -------- | ------------------------------------------------------------------------------------------------------------ |
| 完整文档 | JSON 和必要结构有效、节点 ID 唯一、边端点存在、容器归属合法、禁止非法跨作用域连线、入口唯一性                |
| 执行子图 | 支持的节点类型、配置完整性、DAG 约束、分支端口、变量引用、Output 约束、容器执行约束、角色和 Skill 等运行依赖 |

未使用节点的配置错误可作为编辑提示，不阻塞主流程。接入执行路径后，这些错误恢复为阻塞错误。
全局变量属于工作流级声明，仍保留其现有校验，不因存在未使用节点而放宽。
活动作用域缺少入口仍属于错误。

### 统一消费者

以下消费者必须使用同一套执行范围推导逻辑，不能分别维护过滤规则：

- 创建运行时的角色、Skill 等依赖准备，以及变量池初始化。
- 启动、后续调度、完成判定与变量解析。
- Loop 和 Iteration 内部调度。
- 重启、恢复和交互式继续执行，以及需要执行图的提示词构建。

原始快照与派生执行图明确分离。执行消费者使用派生图，避免从完整快照重新解析后意外恢复未使用节点。
在同一冻结快照上推导结果应确定一致；重启与恢复不采用当前编辑草稿。
调度器同时收紧无入边规则，仅允许合法作用域入口作为起点，防止孤立节点意外进入就绪集合。

## 保存、发布与兼容性

草稿和发布快照完整保留节点、配置、位置及连线。运行时派生图不得覆盖用户文档。
保存、发布、回滚、导入导出和重新打开均应保留备用内容。
既有完全连通工作流保持原行为，原则上无需数据库或本地文件布局迁移。
运行中编辑草稿不会改变已经冻结的执行范围。

## 编辑器与运行视图

- 未使用节点显示“未参与运行”徽标，适度降低视觉强调，保留正常编辑能力。
- 节点说明：“此节点未从开始节点连通，不会参与运行。”容器成员说明应体现所属容器或入口原因。
- 汇总显示“有 N 个节点未参与运行”，不阻止保存、发布或运行。
- 连接、断开、撤销、重做后更新提示；异步分析响应必须匹配当前文档版本，过期结果不得覆盖新状态。
- 运行详情可展示完整快照，但将未使用节点显示为“未参与运行”，不显示为等待执行，也不与分支未命中混淆。
- 不为界面展示创建虚假的 NodeRun。

前端所需参与范围和诊断结果由后端领域分析接口提供，避免重复实现容器可达性规则。
接口只暴露实际消费者需要的节点集合与诊断，不扩大为通用图框架。
按 feature change guide 在 contracts、逻辑操作和 Desktop 绑定的对应所有者声明，并生成客户端及相关产物。
分析请求复用现有请求生命周期机制；切换工作流或卸载时清理请求，避免跨工作流结果泄漏。
翻译由 workflow-editor 及相关运行视图的领域所有者维护。

## 实施顺序

1. 新增执行图推导模块，拆分文档结构检查与执行校验，覆盖根图和容器语义。
2. 统一运行前准备、调度、变量解析、重启与恢复的执行图来源，收紧就绪节点规则。
3. 添加供编辑器使用的最小分析接口，生成契约与绑定，接入节点和汇总提示。
4. 更新运行视图，验证完整快照保留与未参与状态展示。
5. 补齐行为测试，并同步更新 `docs/workflow.md` 和 `docs/workflow.zh.md`，使其描述实际实现后的行为。

## 验证与验收

| 场景                                           | 预期                                                   |
| ---------------------------------------------- | ------------------------------------------------------ |
| 主流程旁有孤立 Agent 或备用链                  | 主流程成功；备用节点无 NodeRun、Session、依赖准备调用  |
| 备用节点角色、Skill 不存在或配置未完成         | 不阻塞主流程；接回执行路径后正常报错                   |
| 不可达节点指向可达节点                         | 不误执行，不阻塞汇合                                   |
| 可达节点引用未使用节点输出                     | 明确校验错误                                           |
| Loop、Iteration 内有备用节点                   | 按各自入口计算，备用成员不执行                         |
| 整个容器不可达                                 | 容器及全部成员不执行，不准备其依赖                     |
| 活动子图存在环、非法分支、无效入口或跨作用域边 | 继续拒绝相应错误                                       |
| Condition 分支选择与汇合                       | 保持现有运行语义                                       |
| 取消、重启、恢复、交互式继续                   | 不激活备用节点，不泄漏资源，不串用其他运行或工作流状态 |
| 保存、发布、回滚、导入导出、重新打开           | 完整保留备用节点、配置及连线                           |
| 连接、断开、撤销重做、快速切换文档             | 提示与最新文档一致，过期分析响应无效                   |
